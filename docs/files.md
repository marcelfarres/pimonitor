# LED Ring Monitor - File Guide

## Core Package

### `pimonitor/`

Python package containing the runtime code:

- `pimonitor/__init__.py` – package marker, re-exports `ServiceMonitor` and `main`
- `pimonitor/kano_hat.py` – Kano hat LED ring + button abstraction
- `pimonitor/monitor.py` – main `ServiceMonitor` implementation and CLI entrypoint

## Configuration

- `led-monitor-cfg.json` – Service configuration (check interval, LED count, targets)

## Service Wrapper

- `led-monitor.py` – Thin wrapper that runs `pimonitor.monitor.main()`
- `led-monitor.service` – Systemd unit file for auto-start on boot

## Tests and Hardware Diagnostics

All test scripts now live under the `tests/` directory:

- `tests/test-monitor.py` – Complete system test (imports, files, config, basic GPIO/LED)
- `tests/led-ring-test.py` – LED hardware test (individual LEDs, colors, rainbow, positions)
- `tests/test-button-detailed.py` – Detailed Kano hat button test with LED feedback
- `tests/test-comprehensive.py` – Comprehensive LED + button diagnostic

## Documentation

- `README.md` – Main installation and usage guide

## Dependency Metadata

- `requirements.txt` – Python dependencies for manual install
- `pyproject.toml` – Project metadata and dependencies for `uv`
- `uv.lock` – Lockfile generated by `uv`
